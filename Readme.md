# Aivan2798 Portfolio — GitHub Pages

Static portfolio centered on the actual projects discussed:
Buuza, Posteye, Zaun Remastered, Zaun UDP, 0xSpyda and Smart Bokx.

## Deploy
Copy the files into a GitHub repository, push to `main`, then use:
**Settings → Pages → Deploy from a branch → main → /root**.

No build system is required.

The GitHub trophy and streak graphics are remote widgets.
